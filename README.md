# 3P Kemeny

Trilingual Astro static site for 3P Kemeny, a chimney installation and relining business serving Ajka and the surrounding area. The site is rebuilt from scraped source content and imagery, with Hungarian as the default language plus English and German localized routes.

## Stack

- Astro static site generation
- Hand-authored localized content data in TypeScript
- Custom responsive CSS with reused scraped image assets
- Cloudflare Pages compatible static output in `dist/`
